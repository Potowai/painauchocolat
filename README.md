# Pain au Chocolat — galerie d'images

Démonstration d'une galerie d'images **Next.js + Cloudinary + Tailwind CSS** :
upload, transformation et affichage optimisé.

## Fonctionnalités

- Galerie d'images servie par Cloudinary
- Transformations à la volée (taille, format, qualité)
- Interface Tailwind responsive
- Image par défaut gérée côté Next.js

## Stack

- **Next.js** + **React**
- **Cloudinary** — stockage et transformation d'images
- **Tailwind CSS**

## Démarrage

```bash
npm install
cp .env.example .env.local   # CLOUDINARY_URL
npm run dev
```
